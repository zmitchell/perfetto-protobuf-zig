# perfetto-protobuf-zig

This repository contains Zig code generated from two sources:
- https://github.com/norma-core/gremlin.zig
  - A pure-Zig protobuf implementation
- https://github.com/google/perfetto/archive/refs/tags/v53.0.tar.gz
  - Perfetto source

The full generated source is under `/gen`, but since there's so much there and there are no imports generated by default, I've only exposed the features that I need via the `root.zig` module. So far that's some pretty basic `Trace` features like tracks and debug annotations.

If you need something more than that, contributions are welcome.
